## 技術詳解:Soft Pseudo + Ensemble Teacher 為什麼有效

### 核心問題

Train 2000 筆混電影 + 商品評論,test 11k 純商品。AdvVal AUC = 0.7468 → **train 跟 test 分布顯著不同**。前 5 天的 16 個方法都在 train 分布上做精修(LS / FGM / threshold / multi-seed / stacking),沒有任何方法讓 student 在訓練時「看到 test 分布」,所以 train 上的微調都被 distribution shift 吃掉。

Soft pseudo 是**少數能讓 student 看到 test 分布的方法**:把 11k test 文字和 teacher 對它們的軟機率一起塞進訓練 batch,student 訓練時就直接接觸 test 文字本身。

### 為什麼 Day 2 的 Hard Pseudo 失敗、Day 6 的 Soft Pseudo 成功

兩者都是「self-training」家族,但訊號性質完全不同:

| 機制 | Day 2 Hard Pseudo | Day 6 Soft Pseudo |
|---|---|---|
| 篩選 | 只收 conf ≥ 0.95 | 收全部 11k(τ=0) |
| Label 形式 | One-hot([1, 0]) | 完整軟分布([0.7, 0.3]) |
| Loss | 標準 CE | soft CE = -Σ p · log q |
| Student 學到的訊息 | 「這筆是 pos,100%」 | 「這筆 70% 是 pos,30% 是 neg」 |
| 訊號性質 | **回音室**:teacher 已 95% 確定的東西再回灌一次 | **不確定性傳遞**:teacher 對 hard cases 的猶豫被當成訓練訊號 |

關鍵差異是**對 hard cases 的態度**:
- Hard pseudo 把 [0.55, 0.45] 的猶豫篩掉(< 0.95 不收),只留 [0.99, 0.01] 這種「沒新資訊」的樣本
- Soft pseudo 把 [0.55, 0.45] 收進來,告訴 student「這個 boundary case 你也只要學到 55% 信心,不用 100%」 → 等於對抗 train 分布的過自信

### 為什麼 alpha=1, tau=0 是甜點

`L = CE(real) + α · soft_CE(pseudo)`,11k pseudo 跟 2k real 的 batch 比例約 5.5:1,單純梯度量上 pseudo 已經主導。然後:
- α 太小(0.3, 0.5)→ pseudo 訊號被稀釋,反而是 real 的 train 分布主導 → 跟 vanilla 趨同
- α=1 → pseudo 跟 real 每筆等權,軟分布訊息完整保留,**5/5 fold best_t spread 收斂到 0.145**(per-fold 收斂是真訊號的指紋)
- α 太大(1.5, 2.0)→ pseudo 過度主導,真實 train label 反被忽略 → spread 又發散

τ=0 而不是 τ=0.7 / 0.9 反直覺但有理:**最不確定的 test 樣本攜帶最多軟分布訊息**(高 entropy),把它們篩掉等於**篩掉訊息**,退化回硬標籤。

### 為什麼 Ensemble Teacher 比 Single Teacher 強

單一 teacher (siebert OOF 0.8890) 跟單一 teacher (electra OOF 0.8880) 都是合理 baseline,但兩個平均之後出現**三項全勝**(F1 0.8945、std 0.0114、spread 0.200),不是「比較好的單模」加總,而是**多樣性 + 校準度的湧現**。

機制:
1. **獨立雜訊互消**:siebert 跟 electra 在不同樣本上犯不同的錯。某筆 siebert 預測 [0.9, 0.1] 自信過頭、electra 預測 [0.6, 0.4] 較保守 → 平均成 [0.75, 0.25],**不會極端錯也不會極端對**,但軟分布更貼近真實機率
2. **架構訊號疊加**:
   - siebert (RoBERTa-large + sentiment FT) 抓 MLM 學到的詞彙 / 短語級情緒
   - electra (Replaced Token Detection) 抓 token-level 的細粒度差異
   - 兩個獨立 inductive bias 在 test 樣本上的 disagreement = 真正的 hard cases
3. **校準度提升**:多模型平均自然降低過自信 → 軟分布更平滑 → student 學到的不確定性更可靠

### 為什麼 Threshold Tuning 這次有效、之前都失敗

之前 threshold 失敗的原因是**主訊號弱 + per-fold 不收斂**:
- multi-seed Mosbach @ 0.62:per-seed best_t spread 0.44,純粹偽訊號
- multi-seed-clean @ 0.46:per-seed spread 0.21,弱訊號 + 主模型也弱(OOF 0.8695 < vanilla 0.8710)→ LB -0.008

這次 threshold 有效的原因是**雙條件同時滿足**:
- ensemble teacher 主訊號最強(OOF 0.8945,LB 0.78402)
- per-fold best_t [0.495, 0.620, 0.420, 0.520, 0.505] 弱收斂(median 0.505、4/5 fold 在 [0.42, 0.52])
- full-OOF best 0.520 落在收斂區間內,不是 outlier 拉出來的偽峰

→ Threshold 是**放大鏡而不是訊號源**:強主訊號上做 threshold 微調 = 放大訊號(LB +0.001);弱主訊號上做 threshold = 放大噪聲(LB -0.008)。

### 整套設計的思路演進(從失敗到成功的鏈)

```
Day 1: vanilla siebert       → LB 0.77107  baseline
Day 2: hard pseudo (.95)     → LB 0.77107  失敗(回音室)
       ↓ [4 天卡關]

       ↓ [想到唯一沒探的軸:soft 形式 + 全 test 樣本]
Day 6: soft pseudo (siebert teacher)
       → OOF 0.8890 +0.018, LB 0.77601 +0.005
       ↓ [想:teacher 還能更強嗎?]
Day 6: ELECTRA-only teacher
       → OOF 0.8880 -0.001, spread 0.395 不穩 → 不交
       ↓ [想:單獨不工作,平均呢?]
Day 6: ensemble teacher (siebert + electra)

       ↓ [兩 LB 提交額度怎麼用?]
```

## 今日核心觀察(LB 已驗證)

### 確認的事

1. **架構多樣性訊號透過 ensemble 才浮現** — 單一 ELECTRA teacher 反而不穩(spread 0.395),siebert + electra 平均後 OOF +0.0055 + std 降低 + LB +0.008 三贏
2. **「老師最強」≠「老師 argmax F1 最高」** — ensemble teacher 內含一個 OOF 0.8675 的 ELECTRA,卻是最強 teacher。Teacher 價值在「軟分布的訊息量」,不是 argmax F1
3. **Threshold tuning 是放大鏡而非訊號源** — 強主訊號上 threshold +0.002 OOF → +0.001 LB;弱主訊號上 threshold +0.001 OOF → -0.008 LB。同一個技巧在不同主訊號上的後果完全相反
4. **Soft pseudo 是這個任務的關鍵突破** — 7 天 +0.014 LB 中有 +0.013 來自 soft pseudo 軸(day6 +0.005 + day7 +0.008),**唯一能讓 student 在訓練時看到 test 分布的方法**

### 方法論教訓

- **判定方法軸時不要被單一配置誤導** — Day 2 hard pseudo 失敗 → 4 天沒人再碰 pseudo;Day 6 soft pseudo 直接突破。下次標記某方法軸「失敗」前,先列清楚是哪個變因失敗(loss 形式 / confidence filter / teacher 來源)
- **Distribution shift 必須從訓練端解決** — train 分布上的所有精修(LS / FGM / threshold / stacking)都會被 distribution shift 吃掉,再多 OOF 提升都不會轉移。soft pseudo 之所以有效是因為它**直接讓 student 訓練時看到 test 文字**
- **失敗 → 推一步前先想「換哪個變因可能反轉」** — Day 6 ELECTRA-only teacher 失敗,沒有立刻放棄架構多樣性,而是測「平均後是否互消雜訊」 → 直接拿到 +0.005 LB

### 競賽結論

7 天從 baseline 0.77107 推到 **0.78539** (+0.01432, 1.86% 相對提升)。核心突破來自 day6-7 的 soft pseudo + ensemble teacher,前 5 天的 16 個訓練端 / inference-time / ensemble / zero-shot 嘗試**沒有任何一個真正動了 LB**。
失敗方法的共通結構:在 train 分布上做精修,沒有引入新訊號。**唯一有效的軸是「在 student 訓練時讓它看到 test 分布的軟標籤」**(soft pseudo),後續又靠「teacher 端引入架構多樣性」(ensemble teacher)+ 「強主訊號上做 threshold tuning」再各加一層。

### 統一解讀

| 方向類別 | 失敗共通機制 |
|---|---|
| Train-side regularization (LS / FGM / multi-seed / stacking / filter) | 改動的是 P_train(Y\|X) 的擬合方式,但泛化目標是 P_test(Y\|X);在 P(X) 不同時不轉移 |
| Inference-time adaptation (T3A) | 假設 high-confidence prediction = correct,但在分布不一致下高信心本身可能有偏 |
| Hard pseudo-labeling / 換 backbone | 訊號重疊,未引入新資訊源 |

→ **可改善 Public LB 的方法,必須使 student 在訓練階段直接接觸 test 分布的 input space**。前 5 天無任何方法達成此條件;day6-7 之 soft pseudo-labeling 為唯一滿足此條件之方案。
