## 嘗試 1:Soft pseudo-labeling 流程設計

### 動機

Day 2 hard pseudo 用 `conf ≥ 0.95` 的 one-hot 當 pseudo label,LB 完全持平 0.77107。本質是 self-distillation 回音室:模型用自己已經很確定的預測再餵自己,沒有新訊息。

Soft pseudo 的差異:**保留 teacher 的整個機率分布** (例: [0.7, 0.3]) 用 soft-CE 訓練,對 hard cases 模型可以表達「這筆其實不確定」,軟標籤本身帶「不確定性」訊息。

### 流程設計(寫於 [pipe_siebert_soft-pseudo.py](../pipe_siebert_soft-pseudo.py))

```
Stage 1 (teacher):
  - 直接讀 testprobs_siebert_vanilla.npy 當 teacher soft labels (預設)
  - 可換成 multi-seed-clean / electra / ensemble (見嘗試 5, 6)

Stage 2 (student soft pseudo fine-tune):
  - 真實 train (2000, hard one-hot) + test (N_keep, soft p_test) 混合
  - Confidence filter τ:keep test sample if max(p_test) >= τ; τ=0 全收
  - Loss = CE(real) + α · soft_CE(pseudo),α 控制 pseudo 訊號強度
  - 5-fold split 只切真實 2000 筆,pseudo 樣本永遠進 train side、
    val 永遠是純真實標籤 — 避免評估失真

Stage 3 (foldwise threshold tuning,寫於 tool_threshold-tune-foldwise.py):
  - 每 fold 各自掃 best_t,看 5 個是否收斂(spread < 0.15)
  - 收斂 → 採 fold-median best_t;發散 → 退回 t=0.5
  - --force-t 旗標可強制覆寫
```

### 關鍵實作細節

- `MixedDataset` 每筆固定包含 `input_ids, attention_mask, labels (hard int), soft_labels (float[2]), is_real (0/1)`,跟 `EvalRealDataset` 介面一致(eval 時 is_real=1 → loss 自動退回純 hard CE)
- `SoftCETrainer.compute_loss` 用 `is_real` mask 拆兩邊算 loss;必須在 `TrainingArguments` 設 `remove_unused_columns=False` 才不會被 HF 砍掉自定義欄位

## 嘗試 2:第一次 soft pseudo 訓練 + 提交 t=0.5

### 配置

`--tau 0.0 --alpha 1.0` (全部 11k test 都收為 pseudo,pseudo loss 跟 real loss 等權)

### 訓練觀察

```
loss 從 1.3 起步, 第 1 epoch 末降到 ~0.6, 之後在 0.4 附近震盪
```

Loss 收在 0.4 是「擬合到 pseudo entropy 下限」的訊號,不是不收斂 — eval F1 在 epoch 之間穩定上升驗證這點。

## 嘗試 3:Alpha sweep

### 動機

第一次跑用 alpha=1 是直覺值,需要驗證是不是真最佳;沿 alpha 軸掃 {0.3, 0.5, 1.0, 1.5, 2.0} 找 plateau。

寫 [tool_sweep-soft-pseudo.py](../tool_sweep-soft-pseudo.py) — 自動 driver,跳過已訓 tag,結尾彙總表。

### 結果

| alpha | F1@0.5 | OOF best_t | OOF best_F1 | fold_med_t | fold_spread | per-fold best_t |
|---|---|---|---|---|---|---|
| 0.30 | 0.8905 | 0.525 | 0.8915 | 0.490 | **0.445** | [0.545, 0.73, 0.285, 0.48, 0.49] |
| 0.50 | 0.8870 | 0.500 | 0.8870 | 0.500 | **0.415** | [0.345, 0.76, 0.42, 0.5, 0.575] |
| **1.00** | **0.8890** | **0.440** | **0.8925** | **0.460** | **0.145** | **[0.39, 0.44, 0.535, 0.46, 0.505]** |
| 1.50 | 0.8835 | 0.620 | 0.8885 | 0.550 | 0.450 | [0.55, 0.73, 0.28, 0.69, 0.53] |
| 2.00 | 0.8890 | 0.525 | 0.8905 | 0.600 | 0.250 | [0.505, 0.725, 0.66, 0.6, 0.475] |

### 觀察

1. argmax F1 在 [0.8835, 0.8905] 之間,範圍只有 0.007,**其實是平台**
2. **alpha=1 是唯一收斂的配置** (spread=0.145),其他 alpha 雖然 F1 不差但 per-fold best_t 都跨 > 0.4 → 全 OOF 上的 best_t 是 fold 抵銷後的偽峰
3. alpha=0.3 的 F1@0.5 略高 (+0.0015) 但發散,Day 5 偽訊號模式

### 結論

固定 alpha=1.0 為主力配置。F1@0.5 的小幅波動是訓練隨機性 (±0.005),要分辨真假需要 multi-seed 平均,成本不划算 → 接受 plateau,不繼續細掃 alpha。

## 嘗試 5:Teacher 多樣性實驗(ELECTRA-only)

### 動機

真正的多樣性來自不同預訓練架構。專案內現成的不同架構模型只有 ELECTRA-large(`testprobs_electra_vanilla.npy` 已存在)— **零訓練成本就能驗證**。

## 嘗試 6:Ensemble teacher (siebert + electra)— 進行中

### 動機

ELECTRA-only 不穩可能是因為單一模型對某些樣本過自信(soft prob 太尖),而 siebert + electra 平均後:
1. 兩個架構**獨立的雜訊互消** → soft prob 更平滑
2. **校準度提升** → soft target 更接近真實機率
3. 同時保留架構多樣性訊號

### 配置

```bash
# Step 1: 算 ensemble teacher probs
python -c "
import numpy as np
a = np.load('outputs/testprobs_siebert_vanilla.npy')
b = np.load('outputs/testprobs_electra_vanilla.npy')
np.save('outputs/testprobs_teacher-siebert-electra.npy', (a + b) / 2)
"

# Step 2: 用 ensemble 當 teacher
python pipe_siebert_soft-pseudo.py --tau 0.0 --alpha 1.0 \
  --teacher outputs/testprobs_teacher-siebert-electra.npy \
  --tag teacher-ens
```

### 結果

```
Fold 1: val F1@0.5 = 0.8925  | best_t = 0.495  best_F1 = 0.8974
Fold 2: val F1@0.5 = 0.9050  | best_t = 0.620  best_F1 = 0.9100
Fold 3: val F1@0.5 = 0.8850  | best_t = 0.420  best_F1 = 0.8900
Fold 4: val F1@0.5 = 0.8800  | best_t = 0.520  best_F1 = 0.8850
Fold 5: val F1@0.5 = 0.9100  | best_t = 0.505  best_F1 = 0.9125
```

### 三 teacher 對比

| teacher | OOF F1 | CV std | spread | 狀態 |
|---|---|---|---|---|
| siebert | 0.8890 | 0.0146 | 0.145 | 弱收斂 |
| electra | 0.8880 | 0.0186 | 0.395 | 發散 |
| **ensemble** | **0.8945** | **0.0114** | 0.200 | 弱收斂帶 1 個 outlier (fold 2 = 0.62) |

ensemble teacher **三項全勝**(F1 最高、std 最低、收斂優於 electra)。OOF +0.0055 vs siebert teacher 超出 ±0.005 噪聲下限,屬真訊號等級。**架構多樣性透過平均浮現**,而非單獨用某個 teacher 就能解鎖。

### Spread 0.200 的判讀

per-fold best_t [0.495, 0.620, 0.420, 0.520, 0.505]:
- 4/5 fold 緊湊在 [0.420, 0.520](range 0.10)
- 1/5 fold 是 0.620(fold 2,F1@0.5 已 0.9050,threshold 對它影響小)
- median = 0.505(基本就是 0.5),mean = 0.512

→ **「弱收斂帶 1 個 outlier」**,主流意見明確支持 t≈0.5,但 full-OOF best_t=0.520 多出 +0.002 邊際空間。

## 今日核心觀察

### 確認的事

1. **Day 5 的「工程上限」結論不對** — 那是 5 個失敗方向給的偽證,沒探到 soft pseudo 軸。LB 0.77107 → 0.77601 直接打破
2. **Hard pseudo vs soft pseudo 是兩種完全不同的東西** — Day 2 hard pseudo 失敗不代表「pseudo-labeling 對此任務無效」,而是 hard label + conf filter 是 self-distillation 回音室;軟分布攜帶的不確定性訊息才是有用的
3. **Alpha 軸是平台不是尖峰** — F1(alpha) 在 [0.3, 2.0] 範圍內波動 < 0.007,屬訓練隨機性;選擇 alpha=1 不是因為它 F1 最高(其實 0.3 略高),而是因為它是**唯一收斂**的配置
4. **Teacher 多樣性的價值依架構搭配而定** — ELECTRA 單獨當 teacher 不工作,要靠 ensemble 平均才可能浮出訊號(嘗試 6 驗證中)

### 還沒確認的事

- t=0.460 fold-median threshold 在 LB 上有沒有額外加分
- Ensemble teacher 是否打破 siebert teacher 0.8890 的天花板
- Soft pseudo 訊號的真正上限 — 換 student 配置(更強訓練)會不會繼續加
