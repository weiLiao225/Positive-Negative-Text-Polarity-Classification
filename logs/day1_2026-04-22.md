## 嘗試 1：roberta-base + DAPT + Fine-tune（失敗）

### 方法

```
roberta-base
→ DAPT（MLM, train+test 全部 ~13k 文本, 3 epochs）
→ Fine-tune（2000 筆, 5 epochs, 10% val split, max_length=128）
```

### 本地結果

- Val Accuracy: 0.8750
- Val F1: 0.8747
- Prediction 分布: Negative=4905, Positive=6095

### Kaggle Public 分數

| 檔名 | Public Score |
|------|-------------|
| roberta-base+DAPT+Fine-tune | **0.75454** |

### 問題分析

1. **Val 0.875 → Kaggle 0.754，落差 12 分**：Val 只有 200 筆，變異極大（95% CI ≈ ±5%），單次 split 不可信
2. **DAPT 可能反而有害**：13k 短句是小語料，DAPT 容易破壞 roberta-base 的 general knowledge
3. 分數低於主辦方 baseline（0.796）

## 嘗試 2：siebert/sentiment-roberta-large-english + 5-fold CV Ensemble（成功）

### 模型選擇理由

- `siebert/sentiment-roberta-large-english` 已在 SST / IMDB / Yelp / Amazon 等二元情緒任務上預訓練
- 本資料分布（電影評論 + 商品評論）與該模型訓練分布高度重疊
- 對比之下，DAPT 在小語料上帶來的效益遠不如直接用情緒預訓練模型

### 方法

```
siebert/sentiment-roberta-large-english
→ 5-fold Stratified CV Fine-tune（每 fold 400 val 筆）
→ 5 個 fold 的 test 機率平均（ensemble）
→ argmax → submission
```

### 主要參數

| 參數 | 值 |
|------|----|
| BASE_MODEL | siebert/sentiment-roberta-large-english |
| MAX_LENGTH | 192（覆蓋 99%+ 樣本）|
| N_FOLDS | 5 |
| FT_EPOCHS | 3 |
| FT_BATCH_SIZE | 8 |
| FT_LR | 1e-5 |
| Early stopping patience | 1 |

### 本地 CV 結果

| Fold | F1 |
|------|----|
| 1 | 0.8700 |
| 2 | 0.8725 |
| 3 | 0.8649 |
| 4 | 0.8675 |
| 5 | 0.8800 |
| **Mean ± Std** | **0.8710 ± 0.0052** |

- std 極小（0.0052），5 fold 結果高度一致，CV 分數可信

### Kaggle Public 分數

| 檔名 | Public Score |
|------|-------------|
| siebert-large_5fold_0871.csv | **0.77107** |

### 結論

- 比 baseline（0.796）低，但 public 只是 33% 測試集，private 結果待觀察
- 與嘗試 1（0.754）相比提升 +0.017，方向正確
- CV 0.871 → Public 0.771 仍有落差，可能原因：test 集分布與 train 略有差異，或 public 33% 子集的特性偏移
