## 嘗試 1：Pseudo-labeling 提交（失敗）

### 方法

- 使用 Day 1 siebert 5-fold 產生的 `avg_probs.npy`
- 篩選 confidence ≥ 0.95 的 test 樣本作為 pseudo label
- 加入訓練集重新做 5-fold fine-tune
- Val 只從原始 2000 筆抽（不含 pseudo label，避免評估失真）

### 本地 CV 結果

```
CV F1 (with pseudo): 0.8744 ± 0.0095
Day 1 baseline     : 0.8710 ± 0.0052
Delta              : +0.0034
```

- Delta 剛在噪音邊界（±0.003），std 從 0.0052 暴增到 0.0095（穩定性下降）
- 當時判斷邊際，但仍提交了

### Kaggle Public 分數

| 檔名 | Public Score |
|------|-------------|
| pseudo-labeling | **0.77107** |

- 和 siebert baseline 完全相同，代表 pseudo label 沒有帶來任何幫助
- 結論：目前模型的系統性錯誤被 pseudo label 強化，distribution shift 問題無法靠自我預測解決

## 嘗試 2：DeBERTa-v3-large（完全失敗）

### 方法

`microsoft/deberta-v3-large` 5-fold 5-fold CV fine-tune

### 失敗歷程

| 版本 | 問題 | 症狀 |
|------|------|------|
| bf16 + lr=5e-6 | disentangled attention fp16 梯度問題 | `Attempting to unscale FP16 gradients` 錯誤 |
| bf16 + lr=1e-5 | classifier head 初始化不良 | train loss 1.5 → 1.42, val F1 = 0.3333 (全預測同一類) |
| bf16 + lr=1e-5 + 手動 init classifier/pooler | bf16 silent gradient bug | loss 0.7 → 1.1 → 0.69 震盪, val F1 = 0.3333 |
| fp32 + lr=1e-5 + batch=4 | 未知崩潰 | loss 幾步後歸零, 完全壞掉 |

### 結論

DeBERTa-v3-large + HuggingFace Trainer 在此環境下無法正常訓練，已放棄。根本原因推測為 DeBERTa-v3 的 disentangled attention 機制與此版本 transformers/accelerate 的 mixed precision 實作有相容性問題。

## 嘗試 3：Siebert + FGM 對抗訓練（效益不顯著）

### 方法

- 繼承 siebert 5-fold pipeline，加入 FGM（Fast Gradient Method）
- 每個 training step：
  1. 正常 forward + backward，累積正常梯度
  2. 擾動 word_embeddings（epsilon=1.0）
  3. 對抗 forward + backward，累積對抗梯度
  4. 還原 embedding，optimizer step
- MAX_LENGTH 改為 128（從 192）、N_FOLDS 改為 3（從 5）以控制時間

### 時間問題

- FGM 每 step 2 倍計算量 → 每 fold 約 47 分鐘（5 fold 預計 235 分鐘）
- 降到 3-fold + max_len=128 後約 100 分鐘

### 本地 CV 結果

```
CV F1 (Siebert + FGM, 3-fold, max_len=128): ~0.869
Day 1 baseline (5-fold, max_len=192)       : 0.8710 ± 0.0052
```

- 幾乎沒有改善（注意比較條件不完全相同：fold 數和 max_len 都不同）
- 沒有提交

### 結論

FGM 對此資料集效益不顯著。可能原因：
- siebert 已是情緒預訓練模型，decision boundary 本就夠平坦
- 根本問題是 distribution shift，FGM 只是 regularization，無法解決

## 今日總結

### 關鍵發現

1. **Pseudo-labeling 無效**（Kaggle 0.771 = baseline）：模型系統性錯誤被強化，iterative pseudo-labeling 也無意義
2. **DeBERTa-v3-large 在此環境不可用**：相容性問題，無解
3. **FGM 邊際效益不足**：Phase 1 策略（regularization/訓練技巧）無法突破瓶頸
4. **核心瓶頸已確認**：CV 0.871 vs Kaggle 0.771 的 10 分落差來自 distribution shift，需要資料層面解決
