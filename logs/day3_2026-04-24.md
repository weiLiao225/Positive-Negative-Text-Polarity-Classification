## 重要發現：資料分布的領域差異

仔細抽樣比對 train 和 test 後發現：

- **Train**: 電影評論（Rotten Tomatoes 風格）+ 商品評論（Amazon 風格）約各半
- **Test**: 幾乎全部是商品/遊戲評論，**幾乎沒有電影評論**

這應該就是 Day 1 起 CV 0.871 vs Kaggle 0.771 落差 10 分的根本原因。

長度分布也不同：
| 指標 | Train | Test |
|------|-------|------|
| max | 254 tokens | 138 tokens |
| 99th | 214 | 118 |
| median | 65 | 69 |

Test 都是短句評論，沒有長篇文章。

## 嘗試 1：Two-Stage Fine-tuning（失敗）

### 方法

```
Stage 1: siebert + Amazon Polarity 30k (filter ≤206 chars) → 1 epoch, lr=5e-6
Stage 2: 從 Stage 1 模型 → 競賽 train 2000 筆 5-fold CV, lr=1e-5
```

理論依據：讓 siebert 適應商品評論語言風格，再對齊競賽 label。

### 結果

| 指標 | 值 |
|------|----|
| Stage 1 amazon val F1 | 0.9620 |
| Stage 2 CV F1 | 0.8644 ± 0.0051 |
| Day 1 baseline CV | 0.8710 ± 0.0052 |
| **Delta** | **-0.0066** |

CV 略低於 baseline 但 std 一樣穩，當下判斷 CV 衡量的有 50% 電影評論而 test 沒有，可能 CV 下降但 Kaggle 上升。

### Kaggle Public 分數

| 檔名 | Public Score | Delta vs Day 1 |
|------|-------------|----------------|
| siebert_two_stage_amazon | **0.75895** | **-0.012** |

CV 下降的確反映到 Kaggle，假設「CV 與 Kaggle 背離」沒有成立。

### 失敗推測

1. **amazon_polarity 的 label 是星數規則產生的，不是文字情緒**：4 星 = 正、2 星 = 負，但 4 星評論可能含混合情緒，標注偏好和競賽不同
2. **Stage 1 可能蓋掉 siebert 對更細微情緒判斷的能力**：filter 後的短評論多半是「Great!」「Terrible!」這種強烈表態，模型學到「短而強烈 = 強信號」，反而在 test 的中性敘述上誤判
3. **30k 可能仍然太多**：lr 雖小但 1 epoch 跑完 3750 steps，足以改變模型權重

## 嘗試 2：NLI Zero-Shot Classification（嚴重失敗）

### 方法

- 模型：`MoritzLaurer/DeBERTa-v3-large-mnli-fever-anli-ling-wanli`
- 純 inference，不訓練
- 對每句 test 計算「The sentiment of this text is positive/negative」的 entailment 分數
- 高分者為預測

### 本地統計

| 指標 | 值 |
|------|----|
| Prediction distribution | Negative=5263 / Positive=5737 |
| Confidence mean | 0.901 |
| Confidence median | 0.984 |
| High conf (>0.9) | 69.7% |
| Low conf (<0.6) | 7.3% |

信心統計看起來「乾淨」，分布平衡，當下判斷值得提交。

### Kaggle Public 分數

| 檔名 | Public Score | Delta vs Day 1 |
|------|-------------|----------------|
| nli_zeroshot_deberta_mnli | **0.72975** | **-0.041** |

最差結果，比 Day 2 的 pseudo-labeling 還慘。

### 失敗推測

1. **NLI 模型的「sentiment」概念和競賽標準不一致**：模型在 MNLI/FEVER/ANLI 上訓練的是「entailment」概念，套到「sentiment」上是借用，可能解讀不同
2. **本地信心統計騙人**：模型很「自信」不代表它對，只代表它對自己的判斷有把握。實際上可能整體偏移
3. **泛用模型對特定領域的盲區**：NLI 模型沒看過商品評論的語境，對「品質很差但便宜可接受」這種混合情緒可能誤判

### 嘗試 3：Model Divergence Analysis（成功釐清問題、無提交）

#### 方法

對 3 組已存的 test 機率做模型分歧分析：
- M1: siebert 5-fold (`avg_probs.npy`)
- M2: two-stage amazon (`avg_probs_two_stage.npy`)
- M3: NLI zero-shot (`avg_probs_nli_zeroshot.npy`)

對每筆 test 樣本計算三模型 positive 機率的標準差作為分歧分數，並比對「高分歧」與「低分歧」樣本的語言特徵（否定詞、轉折詞、混合情緒詞、強調詞、感嘆/問號、大寫比例）。

#### 關鍵結果

| 統計 | 值 |
|------|----|
| 三模型一致 (3:0) | 8969 / 11000 (81.5%) |
| 2:1 分裂 | 2031 / 11000 (18.5%) |
| 三模型皆高信心仍 2:1 分裂 | 739 / 11000 (6.7%) |

**各模型站「少數票」的次數：**
| 模型 | 次數 | 比例 |
|------|------|------|
| M1 siebert | 419 | 3.8% |
| M2 two-stage | 257 | 2.3% |
| M3 NLI | **1355** | **12.3%** |

→ **NLI 確認是 outlier**，少數票頻率是 siebert 的 3.2 倍
→ **siebert 和 two-stage 幾乎是同一個訊號**（96%+ 一致），ensemble 沒有真正多樣性

**語言特徵 delta（高分歧 vs 低分歧）：**

| 特徵 | delta |
|------|------|
| has_negation | -2.9% |
| has_concession | +3.0% |
| has_mixed | +2.8% |
| 其他 | < ±0.04 |

→ **分歧樣本的語言特徵差異極小**，問題不在「詞彙頻率」層面，而在**語境理解**（如「不沾鍋不沾」是讚美、「從沒遇過這種問題」是抱怨）

#### 啟示

1. NLI 不可用，需排除
2. 缺一個「真正獨立」的第二模型來 ensemble
3. 標的：找預訓練資料和 siebert 不重疊的模型

### 嘗試 6：TF-IDF + Siebert Stacking（本地評估後不提交）

#### 方法
- Level-0：siebert OOF + TF-IDF (1-2 grams) → LR + SVM 5-fold OOF + 7 個手工特徵（否定/強情緒/標點/大小寫等）
- Level-1：Logistic Regression (C=0.1) meta-learner
- 全部特徵 StandardScaler 標準化

#### 本地結果

| 指標 | 值 |
|------|----|
| Stacking CV F1 | 0.8690 ± 0.0072 |
| siebert OOF F1 | 0.8710 |
| Delta | **-0.002** |
| 與 siebert 一致率 | 98.3% (10817/11000) |

**Meta-LR 係數（按絕對值排序）：**

| 特徵 | 係數 |
|------|------|
| siebert_pos | +0.95 |
| siebert_neg | -0.95 |
| svm_pos | +0.17 |
| caps_ratio | +0.14 |
| lr_pos | +0.04 |
| 其他 | < ±0.10 |

#### 不提交的理由
1. CV delta -0.002，方向錯
2. 一致率 98.3%，stacking 只改 183 筆，幾乎全是雜訊
3. siebert 係數絕對值是第二高（svm_pos）的 5.7 倍 → meta-learner 自己決定主要還是聽 siebert，TF-IDF 訊號被忽略
4. **TF-IDF 學的是和 siebert 同類型的詞彙模式，diverse signal 不存在**

### 後續方向討論（未執行）

| 方向 | 預期效益 | 風險 | 結論 |
|------|----------|------|------|
| Threshold tuning | +0.000~0.005 | 極低 | siebert 預測已接近 50/50 平衡，調整空間極小 |
| Multi-seed ensemble (3 seeds × 5 folds) | +0.002~0.008 | 低，純 variance reduction | 唯一邏輯清楚的選項 |
| Back-translation | +0.000~0.005 | 中，會破壞諷刺樣本 | 期望值偏負 |
| EDA 同義詞替換 | -0.005~+0.002 | 中，加入噪音 | 不值得 |
| 翻譯到其他語言 | < 0 | 高，諷刺/語境會在翻譯中丟失 | 否決 |
| LLM paraphrase | +0.005~0.015 | 中，但需要 API 預算 | **沒預算，否決** |

#### 對「諷刺/雙重否定」這類深層語意的判斷
- siebert：弱（訓練語料偏直白評論）
- cardiffnlp：略好（Tweet 含諷刺，但通常配 emoji 標記）
- xlm-roberta 等多語模型：對純英文任務反而更弱
- **沒有 LLM API 的前提下，這條路天花板已經到了**

#### 對「Public 33% / Private 67% overfit 風險」的釐清
- Multi-seed ensemble **不會** overfit public：技術本身不接觸 public LB
- 真正會 overfit public 的是「跑多方案、選 public 最高的提交」
- 但 public 樣本只有 ~3630 筆，F1 在 0.77 附近的標準誤差約 ±0.007
- 因此 +0.001~0.005 的 public 改善可能是噪音，private 結果有 ±0.005 隨機波動
